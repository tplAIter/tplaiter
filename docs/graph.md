# Graph observations

`tplaiter graph source|exports|ast|stats --dir <installed-root> --json` exposes separate graph layers. `tplaiter deps graph` uses the same source route. The graph_source, dependency_graph, graph_exports, graph_ast and graph_stats MCP tools use the same compiled CLI backend after domain registration.

Source and exports require `--source-input <file>`: a finite operator-enrolled source selection. Its bytes only locate original signed subjects/evidence; the actual installed runtime admits every source and catalog through its opaque source closure. This inspection basis is **enrolled-source-selection**, not normal installed project dependency enrollment. It supplies no execution permission, organization claim or authority Boolean. The v1 source/engine guards are unchanged.

For exports, repeat `--select base.skill.review --select base.approach.careful`. Bindings are currently empty through CLI/MCP; parameterized entry requests are not exposed by these flags. Unknown/duplicate selectors and missing transitive prerequisites refuse through the existing export selector. Pages preserve complete source pins, export identities, chain metadata and original edges; source, export and syntax digests remain distinct. An edge may reference a node outside the current page. Retrieve all pages to reconstruct a complete native graph.

`--representation page --limit 64` is the default. The response gives total/returned/omitted records and nextCursor. A cursor binds the query and complete graph digest; changed inputs or a different query refuse it. `--representation whole` refuses a graph that cannot fit. `--max-bytes` bounds the **complete CLI result/v1 envelope plus newline**, 1024..32768, default16384. It never trims a record or presents a partial page as a complete graph. For graph MCP tools the same limit additionally bounds the complete SDK JSON-RPC response, including normalized escaped request ID, text summary, structured content and newline. The CLI child measures that exact shared representation before refresh publication; the transport checks the actual final SDK bytes. If the outer metadata/refusal floor alone cannot fit, graph dispatch refuses before any child or graph work with a bounded null-ID transport error. A successful page is reduced only by complete records; whole mode never truncates. This bound is scoped to these five graph tools; other tools retain their existing contracts.

AST analyzes bounded current installed-project files: at most256 supported files, 1MiB/file and16MiB aggregate, with confined no-follow traversal and exact image rechecks on Darwin/Linux. Other platforms refuse unsupported capture. Go facts come from go/parser; Rust is an approximate line outline. Syntax facts are not resolved calls or compiler verification. Parse warnings produce partial status. No compiler, provider, generator, package installer or network executes. Existing semanticgraph Analyze remains unchanged; bounded graph routes use copied byte images.

Default `--cache read` and graph stats never create a cache. Missing/stale/hit/corrupt/disabled/recomputed are explicit cache states; stats that only inspects stored metadata reports **unverified**, not a fresh hit. A read can compute fresh facts without publishing them. Corrupt cache refuses AST retrieval and is reported separately by stats. Cache hits still validate actual current byte images and reparse to verify cached syntax; no cache performance improvement is claimed. `--cache off` skips reuse. Explicit AST `--cache refresh` atomically publishes only bounded rebuildable `.tplaiter/graph-cache` data, then reacquires actual ledger admission and rechecks captured inputs. Refresh is an explicit cache effect; the MCP AST tool is conservatively not marked readonly. It never writes root/dependency locks, journals or registry state. If post-publication reauthentication refuses, the explicitly requested derived cache can remain.

Project admission uses the existing root-scoped reader and retains its root journal guards; it does not scan home credentials or claim whole-home journal verification. A library caller supplying whole-home options still needs the existing genuine secret-classification contract and may be refused.

The CLI holds its owned observation/read coordination until its serialized write completes and closes it on cancellation or broken output. MCP uses the same registered SDK handler through a graph-scoped stdio dispatcher and the existing captured-child route and returns a captured observation; it does not retain a current-state lease through the final MCP output. Later mutation must obtain its own current admission. Graph data and cached syntax cannot manufacture a formatter or execution permit.

This graph domain does not deliver normal nonempty project dependency enrollment/context materialization, dependency installation, semantic edit preview/apply, batch generation transactions or the complete agent apply/verify/docs workflow. Semantic preview remains required separately. Semantic Apply requires an explicit clean-port assessment and recorded primary disposition; it is not silently deferred here.

Refresh calculation does not publish during Prepare. Frame first checks the full graph, expected digest, cursor and actual complete CLI envelope budget and, for graph MCP calls, the actual shared SDK frame budget, then rechecks cancellation, installed admission and source bytes before publication. Publication starts at the first cachePublish call (which may create the derived namespace). Cancellation or reauthentication failure after that point may retain derived cache bytes; success still requires fresh admission. Cancellation observed after the first CAS publication prevents advancing current.json. Known stale digest/cursor or an insufficient admitted frame never starts publication.
