# Linux local-provider acquisition

Linux uses the installed Runtime.OpenLocalProvider route and existing closed registration/project/profile pins. Only pathname Unix stream endpoints are selected; the conservative installed path bound remains 103 bytes. No caller connection, abstract socket, credential JSON, source callback or executable-authority constructor is added.

The endpoint observes every directory through O_NOFOLLOW opens and Fstat/Fstatat identities, validates root ownership/writability before retaining its FD, and explicitly refuses root-direct socket paths. The final non-root parent must be selected-account owned with permission bits 0700. Leaf socket type/owner and complete held parent/name identities are checked before and after DialContext. Aliases, changed identities and unsafe namespace/peer failures remain refusal. The client never unlinks the server namespace; failed acquisition closes owned descriptors, and close deduplicates held FDs without retrying close after EINTR.

SO_PEERCRED is read through the real UnixConn.SyscallConn.Control using the pinned x/sys Ucred wrapper. Kernel UID must match the installed/current effective account and PID must be positive. These establishment-time credentials are account/process observations, not executable, source, publisher or organisation authentication. Qualification remains local-untrusted-observed and codeIdentity unchecked. A pathname connect is not an atomic binding of the inspected inode to the connected peer; same-account/privileged substitution with restored observations is outside this claim.

Only safe initial final-leaf ENOENT after a complete held-parent recheck and live context, or ECONNREFUSED after a complete held leaf/parent recheck and live context, gets the narrow unavailable type. Namespace failure and unsafe errno win over cancellation. Only an actual dial failure matching the canceled/deadline context cause may propagate that context error; a canceled context alone or a joined mixed failure is insufficient. Raw sentinel/missing registration and unsafe refusal retain authentication classification.

The shared acquisition-relative fixed expiry, owned timer, earlier-deadline handling, non-widenable setters, partial write count with terminal failure and idempotent cleanup remain unchanged. Cancellation and expiry never create a usable replacement carrier. Filesystem syscalls before acquisition are not claimed to be preempted by the returned carrier timer.

Build tags select Darwin, Linux, or the unchanged unsupported implementation for other systems. Linux tests separate actual neutral socket credential/namespace observations from explicitly synthetic predicate/mixed-error cases. Socketpair prefix/timer tests are neutral controls, not installed application or authenticated source proof. Offline compilation and tag checks establish no Linux runtime behavior; an installed Linux consumer-to-provider proof requires its own reviewed finite operation plan.
