# Authored modifier constraints and installed projection

`tplaiter.dev/modifier-authored/v2` is a closed, inert authoring contract. It describes exact source content and declared parameters/dependencies plus complete original file, generator, or export records. It does not carry a provider authentication claim, statement CAS, root rule digest, filesystem writer, or execution permission. Documents are bounded to 1 MiB, 16 sources and 256 operations; each original record is bounded to 256 KiB.

Whole-rule `add`, `replace`, and `remove` are supported as pure data calculations. Slots, resurrection/reversal lineage and effect publication are not implemented by this leaf. Original constraints use the producer's complete typed record (including target, mode, content, generator resources, payload and block facts). Matching a name alone is insufficient. Unknown, omitted and duplicate fields, null required collections, unsupported kinds, changed source/declaration facts, missing or ambiguous original records refuse. Native/root admission and content-only source admission remain distinct.

`ProjectAuthoredModifier` takes actual opaque `deps.VerifiedSource` objects. It obtains their SourceReader-produced AcceptedPin, compares authored stable constraints, and rederives the entire root ownership closure from retained bytes. Caller-supplied catalogs, rule maps and receipts cannot replace that source. Each unique matched original record maps to the current exact ID, digest and version. Existing modifier/v1 validation and ResolveModifiers still check the projected runtime ExpectedDigest; runtime CAS and source verification are never bypassed.

Root rule IDs hash complete original records and remain stable when those records are identical. Root rule digests bind the full admitted runtime closure, including actual evidence and source declaration; they may differ across legitimate installations of the same commit. Public author documents therefore contain semantic records, while each installation projects its own evidence-bound digests. Existing root51 identities and all v1 contracts remain unchanged.

The exported pure projection returns defensive DATA for inspection only. It is not a publication certificate. `contextsource.PreparedNativeModifier` retains original authored bytes, exact source reads/resolutions and projection under one actual installed Runtime. Constructor and RecheckFor reverify each original subject/evidence, run SourceReader again, and reconstruct all root rules. A different or closed runtime/carrier refuses. The opaque carrier exposes no effect material getter, callback or writer map.

Authored bytes supplied as calculation input are not automatically an upstream source-published descriptor. Binding an admitted descriptor path, target ownership/read lease, source/action permits, staged material, complete root/dependency locks/resources/ledgers, conditionalApply, conversion/reversal and cold reconstruction requires the separately owned shared native material/writer route. This leaf does not extend operation permissions, launch tools, write projects, or complete Next conversion. No alternative writer or fabricated PreparedNew exists.

Future descriptor publication must refer to an actual earlier content commit, avoiding self-commit recursion. Next authored catalog, package slot ownership and test configuration need separately reviewed content/schema changes. The existing Next content contract cannot be relabeled as a native root or source permit.
