# << .Name >> — tplaiter template repository

This is a template repository compatible with [tplaiter](https://github.com/tplAIter/tplaiter).
It is generated by the `tplaiter init-template << .Name >>` command and contains a working
minimal example with all tools: settings manifest, `files/` tree,
generators, ai-config, and environment playbooks.

## Quick start for maintainers

```sh
tplaiter lint-template         # self-test: render all edge-case setting combinations
```

Edit `template.manifest.yaml` (setting groups, commands, hooks), the
`files/` tree (project templates), and `ai-config/` (rules for AI assistants).
Development conventions are described in `ai-config/rules/00-base.md`.

## Publishing versions

Template versions are git tags (SemVer):

```sh
git tag v0.1.0
git push origin v0.1.0
```

- single-repo (one template at root): tag like `vX.Y.Z`;
- multi-repo (`repo.manifest.yaml` + subdirectories): tag like `<template-name>/vX.Y.Z`.

`tplaiter new <ref>` without `@version` takes the latest stable tag; if no
tags exist — the branch HEAD (with a warning).

## Connecting a repository

```sh
tplaiter repo add mycompany <url-of-this-repository>
tplaiter template list
tplaiter new mycompany/<< .Name >> my-project
```

## CI

`.github/workflows/template.yml` runs `tplaiter lint-template` and matrix
rendering for edge-case combinations (`--combo`). Keep checks green before
publishing a tag.

tplaiter documentation: https://github.com/tplAIter/tplaiter
